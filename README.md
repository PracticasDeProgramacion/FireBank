# FireBank
Pagina web de pruebas.
🏦 Simulador de Banca Online
⚠️ AVISO IMPORTANTE: PROYECTO FICTICIO, EDUCATIVO Y EXCLUSIVAMENTE PARA PRUEBAS.

Esta aplicación no es un banco real, no ofrece servicios financieros y no debe utilizarse con información personal, bancaria o confidencial. Todas las cuentas, operaciones, saldos y transacciones que aparecen en ella son ficticios.
📌 Descripción del proyecto

Este proyecto consiste en una aplicación web que simula la experiencia de una plataforma de banca online. Su objetivo es ofrecer un entorno visual e interactivo para realizar pruebas, experimentar con interfaces web, practicar flujos de navegación y explorar funcionalidades habituales de una aplicación bancaria.

La aplicación está fuertemente inspirada en Zero Bank — Zero Web Application Security, tomando como referencia su concepto de banca online de demostración y algunos de los patrones de navegación propios de este tipo de plataformas.

Este proyecto es una implementación independiente con fines de aprendizaje y experimentación. No es una aplicación oficial de Zero Bank, no está afiliada a sus responsables y no pretende ofrecer servicios bancarios reales.

🎯 Objetivos
Simular la experiencia de usuario de una plataforma bancaria.
Practicar el desarrollo y la interacción con interfaces web.
Disponer de un entorno de pruebas para explorar flujos de inicio de sesión y registro.
Mostrar operaciones bancarias ficticias mediante una interfaz visual.
Facilitar demostraciones, experimentación y pruebas manuales.
Explorar el desarrollo asistido por inteligencia artificial.
✨ Características

La aplicación puede incluir, según las funcionalidades implementadas en la versión actual:

🔐 Inicio de sesión simulado: permite acceder a la interfaz de demostración sin verificar credenciales bancarias reales.
📝 Registro ficticio: permite crear cuentas de prueba para experimentar con el flujo de registro.
👤 Perfiles de demostración: usuarios y datos completamente ficticios.
💳 Cuentas simuladas: representación visual de cuentas y saldos sin valor monetario real.
📊 Panel de usuario: interfaz para consultar información ficticia.
💸 Operaciones simuladas: representación de movimientos y transacciones sin transferencias reales.
🧭 Navegación interactiva: diferentes secciones para explorar la experiencia de banca online.
La disponibilidad de cada funcionalidad depende de la implementación actual del proyecto. Ninguna operación debe interpretarse como una operación financiera real.
🔑 Acceso y creación de cuentas

La aplicación está diseñada para facilitar las pruebas sin necesidad de utilizar credenciales reales.

Inicio de sesión

Es posible acceder introduciendo valores de prueba en los campos de usuario y contraseña. La aplicación no requiere credenciales bancarias auténticas y puede aceptar datos arbitrarios, según la lógica implementada.

Registro de usuarios

El formulario de registro permite crear usuarios ficticios para probar la experiencia de creación de cuentas.

Los datos introducidos se utilizan únicamente para el funcionamiento de la simulación en el navegador, de acuerdo con la implementación actual.

Importante: que el formulario acepte cualquier valor no significa que exista una autenticación real ni que la cuenta creada tenga validez fuera de la aplicación.

🔒 Privacidad y tratamiento de datos

La aplicación se ha concebido para funcionar como una demostración local en el navegador, sin un sistema bancario real ni un servicio de autenticación financiera.

¿Qué ocurre con los datos introducidos?
No se envían intencionadamente a un servidor de la aplicación: los formularios están destinados a la simulación local.
No se realizan operaciones bancarias reales: no se mueve dinero ni se contacta con entidades financieras para ejecutar transacciones.
Los usuarios y las operaciones son ficticios: los datos mostrados carecen de validez financiera.
El almacenamiento es temporal: los datos de prueba pueden mantenerse en la memoria de la aplicación o en el almacenamiento del navegador, según la implementación.
Los datos pueden desaparecer: al recargar la página, cerrar el navegador, limpiar los datos del sitio o reiniciar la aplicación, la información puede perderse. El comportamiento exacto depende del mecanismo de almacenamiento utilizado.
🚫 No introduzcas información real

Aunque la aplicación esté diseñada para no transmitir los datos introducidos a un servidor propio, NO introduzcas información privada, real o confidencial.

No utilices:

Contraseñas reales ni contraseñas que utilices en otros servicios.
Nombres de usuario asociados a cuentas personales.
Números de tarjetas de crédito o débito.
IBAN, números de cuenta u otros identificadores bancarios.
Datos personales, direcciones, teléfonos o documentos de identidad.
Información financiera, credenciales corporativas o cualquier otro dato sensible.

Utiliza exclusivamente datos inventados para las pruebas.

Nota técnica sobre la privacidad

La ausencia de un backend propio no garantiza, por sí sola, que absolutamente ningún dato pueda salir del dispositivo. El alojamiento web, los servicios de terceros, las herramientas de analítica, las extensiones del navegador o las solicitudes de recursos externos podrían tener comportamientos independientes.

Por ello, no debe interpretarse esta declaración como una auditoría técnica de privacidad ni como una garantía absoluta sobre toda la infraestructura donde se publique la aplicación.
